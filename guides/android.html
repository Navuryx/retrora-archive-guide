Android

Android is the one mobile platform where a copy is complete and readable: the APK files are not encrypted, and the tool reads them fully. You need a computer with adb, or the tool on the phone itself in Termux.

1. Stop updates

Fortnite on Android comes from the Epic Games app or the Samsung Galaxy Store. Turn off automatic updates in whichever one installed it, before you start.

2. Set up adb

  1. Install Android's platform-tools on the computer:
    • Windows: winget install Google.PlatformTools, or download platform-tools and unzip it.
    • macOS: brew install android-platform-tools.
    • Linux: sudo apt install adb (or your distribution's package).
  2. On the phone: Settings > About phone, tap Build number seven times. Then Settings > System > Developer options and turn on USB debugging.
  3. Connect the phone with a cable and run adb devices. Accept the prompt on the phone. The phone should now be listed as device.

3. Copy the app (APKs)

  1. Find the version you have: 
    adb shell dumpsys package com.epicgames.fortnite | grep versionName
    (on Windows PowerShell, use | findstr versionName).
  2. List the app's files. Modern installs are split into several APKs: 
    adb shell pm path com.epicgames.fortnite
    Each line is package:/data/app/.../base.apk or .../split_*.apk.
  3. Pull every one of them into a folder named after the version: 
    mkdir fortnite-android-28.01
cd fortnite-android-28.01
adb pull /data/app/.../base.apk
adb pull /data/app/.../split_config.arm64_v8a.apk
    (one adb pull per line from the previous step, with the path after package:).

4. Copy the downloaded game files

Fortnite downloads most of the game after it is installed. Those files live in the app's folder on shared storage. Pull them too, or the copy is only the installer:

adb pull /sdcard/Android/data/com.epicgames.fortnite/files fortnite-android-28.01/files

This can be several gigabytes. If the phone refuses access to that folder, connect it over USB in file transfer mode and copy Android/data/com.epicgames.fortnite with the computer's file manager.

5. Check the copy

retrora-archive identify fortnite-android-28.01/base.apk
retrora-archive manifest fortnite-android-28.01 fortnite-android-28.01.json

6. Put it back

adb install-multiple fortnite-android-28.01/base.apk fortnite-android-28.01/split_*.apk
adb push fortnite-android-28.01/files /sdcard/Android/data/com.epicgames.fortnite/

Android only installs a version over an older one. To go back to an older copy, uninstall Fortnite first (which deletes its downloaded files), then install the copy.

7. The tool on the phone (Termux)

  1. Install Termux from F-Droid (the Play Store version is out of date).
  2. In Termux, allow storage access and copy the tool into Termux's own folder. Shared storage cannot run programs: 
    termux-setup-storage
cp ~/storage/downloads/Fortnite-Archive-Tool-android-arm64-termux ~/retrora-archive
cd ~ && chmod +x retrora-archive
./retrora-archive identify ~/storage/shared/Download/Fortnite.apk

8. Common problems

  • unauthorized in adb devices: unlock the phone and accept the USB debugging prompt.
  • Only base.apk installs and the game will not open: the split APKs are missing. Use install-multiple with all of them.
  • INSTALL_FAILED_VERSION_DOWNGRADE: uninstall the newer Fortnite first.
