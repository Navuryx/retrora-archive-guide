Linux and Steam Deck

Fortnite builds on Linux and the Steam Deck are the Windows builds, run through Proton or Wine. Keeping one is copying its folder; the tool runs in a terminal.

On this page
  1. Steam Deck: Desktop Mode
  2. Running the tool
  3. External drives
  4. Common problems

1. Steam Deck: Desktop Mode

  1. Press the Steam button, Power > Switch to Desktop.
  2. Open Firefox (or the Discover store to install it) and download the Linux and Steam Deck tool.
  3. Open Konsole from the application menu (System > Konsole). A keyboard and mouse help; the on-screen keyboard is Steam + X.

2. Running the tool

cd ~/Downloads
unzip Fortnite-Archive-Tool-linux-x64-steamdeck.zip
cd Fortnite-Archive-Tool-linux-x64-steamdeck
chmod +x retrora-archive
./retrora-archive identify "/path/to/Fortnite 12.41"
./retrora-archive manifest "/path/to/Fortnite 12.41" "fortnite-12.41.json"

On an ARM computer, use the Linux ARM download instead.

3. External drives

  • exFAT works on Windows, macOS, Linux and the Deck: the simplest choice for a drive you move between them.
  • ext4 is best when the drive stays on Linux. Keep file permissions with cp -a "Fortnite 12.41" /run/media/$USER/Backup/.
  • On the Deck, drives and microSD cards appear under /run/media/deck/.

4. Common problems

  • "Permission denied": run chmod +x retrora-archive, and run it from a Linux-formatted folder (programs cannot run from some exFAT or NTFS mounts).
  • "No such file or directory" for a file that exists: you have the ARM download on an x86 computer, or the reverse.
