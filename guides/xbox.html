Xbox One and Series X|S

The Xbox can copy an installed game to a USB drive by itself. That drive is your archive. To keep it on a computer as well, make a whole-drive image.

1. What you need

  • A USB 3.0 (or newer) drive of 128 GB or more. Formatting erases it.
  • The Xbox signed in to the account that owns Fortnite.

2. Stop updates

Settings > System > Updates: turn off Keep my games & apps up to date. Do this before the console sees a new Fortnite version.

3. Format the drive for games

  1. Plug the drive into the Xbox. If it asks how to use the drive, choose Format storage device.
  2. Otherwise: Settings > System > Storage devices, select the drive, then Format for games & apps. Give it a name such as Fortnite archive.

4. Copy Fortnite to the drive

  1. My games & apps > See all > Games, highlight Fortnite and press the Menu button.
  2. Manage game and add-ons, then Move or copy (on the right).
  3. Choose the USB drive and Copy selected. Copy keeps the internal one too; Move takes it off the console.
  4. When it finishes, the drive holds that version. Label the drive with the version and date.

5. Keep an image of the drive on a computer

Windows does not open a drive formatted by an Xbox, and you should not let it "fix" or format the drive. Make a sector-by-sector image instead, which copies the drive exactly as it is.

On Linux (or a Steam Deck in Desktop Mode)

  1. Plug in the drive and find it: lsblk. It is the disk whose size matches, for example /dev/sdb (the whole disk, not a numbered partition).
  2. Image it to another drive with enough room: 
    sudo dd if=/dev/sdb of=/media/backup/xbox-fortnite.img bs=4M status=progress conv=fsync
  3. Put the image in its own folder and make a manifest: 
    retrora-archive manifest /media/backup/xbox-fortnite xbox-fortnite.json

On Windows

Use a disk-imaging program that can read a whole device into an image file (a "read" or "create image" of the disk, not of a partition). When Windows offers to format the drive, choose Cancel.

Double-check the device name before running dd. Swapping if and of overwrites the drive.

6. Put it back

  • Plug the drive into the Xbox. Fortnite shows in My games & apps and can be played or copied back to the console the same way. It plays with the account that owns it.
  • From an image: write it back to a drive of the same size or larger with sudo dd if=xbox-fortnite.img of=/dev/sdb bs=4M status=progress conv=fsync.
Fortnite's own servers only accept the newest version, so an old copy is an archive, not a way to play online. Games built for Series X|S can be stored on a USB drive but must be copied back inside to play.

7. Common problems

  • "Move or copy" is missing: the drive is not formatted for games, or it is USB 2.0.
  • The copy is grey on another console: sign in with the account that owns Fortnite.
