macOS

Two things on a Mac: running the Archive Tool (macOS blocks programs it does not know), and keeping a Mac build of Fortnite. Fortnite ran on Macs until Chapter 2 Season 3 (13.40, 2020).

On this page
  1. Which download
  2. Running the tool
  3. Keeping a Mac build
  4. Common problems

1. The download

One disk image runs on every Mac, Apple Silicon and Intel.

Download for macOS

2. Running the tool

  1. Double-click Fortnite-Archive-Tool-macos.dmg in Downloads. A disk named Archive Tool opens with the program and its README.
  2. Open Terminal (Applications > Utilities) and copy the program to your home folder: 
    cp "/Volumes/Archive Tool/Fortnite Archive Tool" ~/retrora-archive
cd ~
  3. macOS blocks programs downloaded from the internet that are not notarised. Remove that mark from this one file: 
    xattr -c retrora-archive
    Or run it once, then open System Settings > Privacy & Security and choose Allow Anyway.
  4. Run it: 
    ./retrora-archive identify "/Users/Shared/Epic Games/Fortnite"

3. Keeping a Mac build

  1. In the Epic Games Launcher, turn off Auto-Update for Fortnite (Library, ..., Manage).
  2. The game is in /Users/Shared/Epic Games/Fortnite. Quit the game and the launcher, then copy that folder to another drive in Finder.
  3. Check it: 
    ./retrora-archive identify "/Volumes/Backup/Fortnite 13.40"
./retrora-archive manifest "/Volumes/Backup/Fortnite 13.40" "/Volumes/Backup/Fortnite 13.40.json"

4. Common problems

  • "cannot be opened because the developer cannot be verified": use the xattr step above.
  • "Bad CPU type in executable": the Mac runs a macOS older than 10.12, which the tool does not support.
  • "Permission denied": run chmod +x retrora-archive.
