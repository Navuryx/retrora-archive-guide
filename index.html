Keep the Fortnite builds you own

Fortnite updates itself and the version you had is gone. These guides show how to keep a copy on every platform, and the Fortnite Archive Tool tells you exactly what each copy is and proves it stays intact.

Before anything else, turn off automatic updates on your console, phone or launcher. Once the game updates, the old version is replaced. Archive first, update after.

Fortnite Archive Tool

A small command-line program. It reads a build or a copy from any platform and names it: platform, container, release, version and changelist. It writes a manifest of every file (SHA-1 and SHA-256), checks copies against it, unpacks zip, IPA and APK files safely, and packs a build into one file. Each download is the program itself, nothing to unzip. Every one is also on the latest release.

Windows (the simple case)

  1. In the Epic Games Launcher, Library, open Fortnite's ... menu, then Manage, and turn off Auto-Update. The install folder is shown there (usually C:\Program Files\Epic Games\Fortnite).
  2. Close the game and the launcher, then copy the whole folder to another drive.
  3. Open PowerShell in Downloads (where the tool is) and run: 
    .\Fortnite-Archive-Tool-windows-x64.exe identify "E:\Fortnite 12.41"
.\Fortnite-Archive-Tool-windows-x64.exe manifest "E:\Fortnite 12.41" "E:\Fortnite 12.41.json"

Commands

CommandWhat it does
identify <file or folder> [--json]Platform, container, release, version and changelist, read from the build itself
manifest <folder> <file.json>Every file with its size, SHA-1 and SHA-256
verify <folder> <file.json>Missing, changed and extra files against a manifest
paks <file.pak or folder>Lists the files inside Unreal paks whose index is not encrypted (Chapter 1 builds)
extract <zip, ipa or apk> <folder>Unpacks; no entry can land outside the folder. For 7z and RAR use 7-Zip
pack <folder> <file.zip>Packs a build with its manifest inside

What the tool never does

It never decrypts. Console packages, App Store copies and encrypted pak indexes are named as encrypted and left closed. Copies made with these guides stay tied to your device or account, exactly as the device made them.
