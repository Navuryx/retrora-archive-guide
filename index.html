Keep the Fortnite builds you own

Fortnite updates itself and the old version is gone. These guides show how to keep a copy of the version you have on every platform. The Fortnite Archive Tool then tells you exactly what each copy is, and proves it stays intact.

Before anything else: turn off automatic updates on your console, phone or launcher. Once the game updates, the version you had is replaced. Archive first, then update.

Fortnite Archive Tool

A small command-line program. It reads a build or a copy from any platform and says what it is: the platform, the container, the release, version and changelist. It writes a manifest of every file (SHA-1 and SHA-256) so you can check a copy later, unpacks zip, IPA and APK files safely, and packs a build into one file.

Quick start

Unzip the tool, open a terminal in that folder (on macOS and Linux, run chmod +x retrora-archive once), then:

# What is this build?
retrora-archive identify "D:\Builds\Fortnite 12.41"

# A manifest of every file, to check copies against later
retrora-archive manifest "D:\Builds\Fortnite 12.41" fortnite-12.41.json

# Is this copy still the same?
retrora-archive verify "E:\Backup\Fortnite 12.41" fortnite-12.41.json

# Unpack an IPA, APK or zip safely
retrora-archive extract Fortnite.ipa Fortnite-ipa

# One file holding the build and its manifest
retrora-archive pack "D:\Builds\Fortnite 12.41" fortnite-12.41.zip
CommandWhat it does
identify <file or folder> [--json]Platform, container, release, version and changelist, read from the build itself
manifest <folder> <file.json>Every file with its size, SHA-1 and SHA-256
verify <folder> <file.json>Missing, changed and extra files against a manifest
paks <file.pak or folder>Lists the files inside Unreal paks whose index is not encrypted (Chapter 1 builds)
extract <zip, ipa or apk> <folder>Unpacks; no entry can land outside the folder. For 7z and RAR use 7-Zip
pack <folder> <file.zip>Packs a build with its manifest inside

Windows, macOS, Linux and Steam Deck

A PC build is a folder. Copy the whole folder before the launcher updates it.

  1. Epic Games Launcher: in Library, open Fortnite's ... menu, then Manage, and turn off Auto-Update. The folder is shown there too (usually C:\Program Files\Epic Games\Fortnite).
  2. Close the game and the launcher, then copy the folder to another drive.
  3. Run retrora-archive identify on the copy, then retrora-archive manifest, and keep the manifest beside it.

Steam Deck and Linux: a Windows build copied the same way is read with the Linux tool. On a Mac, the Mac build is an .app; the tool reads it as it is.

iOS (iPhone and iPad)

Recommended: ipatool

ipatool is a free, open-source command-line program (Windows, macOS, Linux) that downloads the .ipa of an app on your Apple ID, straight from Apple.

  1. Install it from its releases page (or brew install ipatool on a Mac).
  2. Sign in with your Apple ID: ipatool auth login --email you@example.com.
  3. Find Fortnite: ipatool search Fortnite, and note its bundle ID.
  4. Download it: ipatool download --bundle-identifier <bundle ID> --output Fortnite.ipa.
  5. Newer ipatool versions can list and download the older versions Apple still serves for an app you own (ipatool list-versions, then download --external-version-id). Run ipatool --help to see what yours supports.
  6. Then retrora-archive identify Fortnite.ipa and retrora-archive manifest on the unpacked copy.

Old versions you may already have

Before iTunes 12.7 (2017), iTunes kept every synced app as an .ipa file. On an old PC or Mac, look in Music\iTunes\iTunes Media\Mobile Applications. Fortnite copies from 2018 to 2020 turn up there if the phone was ever synced with iTunes. Copy them somewhere safe.

Also works: Apple Configurator (Mac)

While Apple Configurator adds an app you own to a connected device, it keeps the downloaded .ipa in its cache (~/Library/Group Containers/K36BKF7T3D.group.com.apple.configurator/Library/Caches/Assets/TemporaryItems/MobileApps/). Copy it from there before the install finishes.

An iPhone backup (Finder, iTunes or iCloud) does not contain apps, only their data. App Store copies are encrypted for your Apple ID; the tool says so and leaves them closed.

Android

Android packages are not encrypted, so this is a full copy that the tool reads completely.

  1. On the phone: Settings > About phone, tap Build number seven times, then turn on Developer options > USB debugging.
  2. On a computer with Android platform-tools: adb shell pm path com.epicgames.fortnite lists the package parts.
  3. adb pull each path it lists (base.apk and its split_*.apk files).
  4. retrora-archive identify base.apk reads the release and version.

Xbox (One and Series X|S)

  1. Turn off Settings > System > Updates > Keep my games & apps up to date.
  2. Plug in a USB 3 drive. Under Settings > System > Storage devices, format it for games. This erases the drive.
  3. Open My games & apps, then Fortnite, Manage game and add-ons, Move or copy, and Copy it to the USB drive.
  4. Keep that drive as the archive. It copies back to an Xbox the same way.
The copy is encrypted and plays only on Xbox with your account. Windows does not open a drive formatted by an Xbox, so keep the drive whole, or image it with a disk-imaging tool.

PlayStation (PS4 and PS5)

PS5

  1. Turn off automatic updates under Settings > Saved Data and Game/App Settings > Automatic Updates.
  2. Settings > Storage > USB Extended Storage: format a USB drive. This erases the drive.
  3. In the Game Library, choose Fortnite, press the ... button, then Move to the USB drive. Keep the drive.

PS4

  1. Turn off Settings > System > Automatic Downloads.
  2. Settings > System > Back Up and Restore > Back Up PS4 to a USB drive. Every installed game, Fortnite included, goes into one backup that restores to a PS4 signed in to the same account.
Both copies are encrypted to your console and account.

Nintendo Switch

  1. Turn off System Settings > System > Auto-Update Software.
  2. Put in a microSD card, then System Settings > Data Management > Manage Software > Fortnite > Move Data to the microSD card.
  3. Turn the Switch off, put the card in a computer and copy the card's whole Nintendo folder somewhere safe. It can be copied back to the card later.
The files are encrypted to that Switch.

What the tool never does

It never decrypts. Console packages, App Store copies and encrypted pak indexes are named as encrypted and left closed. Breaking a copy protection is not something the tool or these guides do or explain. It keeps, checks, unpacks and packs the copies you have, as they are.
